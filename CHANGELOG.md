# Changelog

## 0.1.0 — Initial preview (2026-10-22)

- Local-only `inspect`, `convert` and `verify` commands.
- Markdown, generic JSONL, selected Codex and Claude Code JSONL text-record adapters.
- Heuristic credential masking, optional personal-contact masking, project-scoped deduplication.
- Versioned JSON and readable Markdown export, atomic output behavior and cross-platform tests.

This initial preview has no usage/adoption claims and no hosted service.
