# Contributing to ContextPort

Contributions, documentation corrections, security tests and carefully scoped new adapters are welcome.

1. Open an issue describing a reproducible problem or proposed improvement.
2. Fork, create a branch and use `npm ci`, `npm test`, `npm run check`.
3. Add a failing test first for changed behavior, then implement the fix.
4. Include only **synthetic examples**. Do not commit exported real conversations, absolute home paths, API tokens, credentials, or other people's private records.
5. Keep the CLI offline and dependency-light. Document new record-shape support and limitations.

By contributing code, you agree it is licensed under the repository's MIT license.
